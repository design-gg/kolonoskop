Варианты анимации

☝ Наведите курсор на баннер, чтобы увидеть анимацию

Для удобства сравнения анимации запускаются по наведению, чтобы все баннеры не двигались одновременно. При реальном размещении они воспроизводятся автоматически.

Все баннеры загружаются из общей папки banners. Для добавления следующих вариантов достаточно указать их номера в конфигурации страницы.
